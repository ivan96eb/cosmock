cosmock documentation
=====================

``cosmock`` generates mock weak-lensing convergence (``kappa``) maps from
an input kappa map and its angular power spectra. The package implements a
generalized point-transformed Gaussian workflow for fast mock-field
generation.

Start with the installation and quickstart pages to test the
standard workflow.
